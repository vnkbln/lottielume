# Changelog

## 1.0.0-beta.1

First public Windows beta, consolidating private development:

- GPU Player and independent Emitter instances.
- Integrated sequential/random playlists, activation advance and Previous/Next.
- Per-spawn source, speed, opacity, transform and palette.
- Vector transforms, four fit modes and optional crop.
- Four-color palette, gradients and AE Fill support.
- Embedded square LottieLogo, icons and 130-animation Centerline pack.
- Pinned build, licenses, notices and local release packaging.

Private builds changed parameter schemas: back up old compositions/presets. No .lottie or macOS support yet.
