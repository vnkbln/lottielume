# Lottie Emitter

Spawn starts an independent instance. Spawn Options contains Speed, Opacity, Max Instances, Spawn on Start and Clear. Opacity multiplies authored transparency.

Each spawn captures source, speed, opacity, transforms and palette. Navigation does not replace active sources. Spawn on Change emits on Previous/Next. Disconnect clears instances and queued work; Connect can invoke Spawn on Start. Map Spawn through Resolume for audio control. Speed has no automatic BPM synchronization.
