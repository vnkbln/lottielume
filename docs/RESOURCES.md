# Resources

Embedded/external PNG, JPEG, WebP, TTF, OTF and expressions work within ThorVG's supported subset. External files must remain accessible relative to JSON. Embedding improves portability.

Select the same JSON again to reload resources. Reload is hidden. Missing references can be replaced through the file selector; save the composition after replacement. Palette controls do not recolor raster pixels. .lottie is not supported yet.
